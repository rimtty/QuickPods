# QuickPods app icon — generation prompt

- Generation mode: built-in ImageGen
- Use case: `logo-brand`
- Intended use: Windows desktop application icon and system-tray brand mark

## Final prompt

Create one original, compact icon mark that communicates instant volume control and wireless audio. Build a bold geometric “Q” silhouette from a circular audio-control ring combined with a minimal headphone cue; let the Q tail subtly suggest a short sound wave. The mark must feel specific to QuickPods without using a wordmark.

Use crisp vector-like flat shapes inspired by Windows 11 Fluent Design while remaining original. Center a single rounded-square app tile with generous, even padding and a strong silhouette. Keep every important detail thick enough to remain legible at 16, 24, and 32 pixels.

Use a deep charcoal-navy tile, a bright cyan/aqua symbol, and a small off-white highlight only if essential. Do not include text, typographic letters, Apple/AirPods silhouettes, Microsoft or third-party logos, trademarked shapes, a generic Bluetooth rune, music notes, a microphone, gradients, 3D rendering, glossy bevels, thin lines, tiny decorative details, complex earbuds, mockup presentation, or a watermark.

Generate on a perfectly flat solid `#ff00ff` chroma-key background with no shadows, gradients, textures, reflections, floor plane, or lighting variation outside the tile. Do not use magenta or pink inside the icon.

## Output files

- `quickpods-icon.png`: final 1024×1024 RGBA PNG
- `quickpods-icon.ico`: Windows multi-resolution icon containing 16, 20, 24, 32, 40, 48, 64, 128, and 256 px images
- `quickpods-icon-alpha-master.png`: original-resolution transparent master
- `quickpods-icon-source.png`: original chroma-key generation
- `quickpods-icon-size-preview.png`: small-size legibility check
