# Support

QuickPods is a community-maintained project provided without a support SLA.

Before opening an issue:

1. Confirm that the system meets the [requirements](README.md#requirements).
2. Review the [user guide](docs/user-guide.md), [troubleshooting guide](docs/troubleshooting.md), and [known limitations](docs/release/known-limitations.md).
3. Reproduce the problem with the latest release or current `main` build.
4. Remove private identifiers from logs and screenshots as described in [SECURITY.md](SECURITY.md).

Use a bug report for a reproducible defect and a feature request for a focused proposal. General Windows, Bluetooth-driver, headset, or hardware support questions may be outside the scope of this project.
